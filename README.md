# Random-Race-Generator-by-uhmmm_
A simple browser-based random race simulator.

## What it does

- Lets you choose a racing series: **NASCAR**, **Formula 1**, or **WEC**.
- Lets you pick a real race from that series calendar.
- Simulates race results using real drivers from the latest verified season data in the app.
- Shows a podium, top 10, and a generated race summary.

## Run it

Open `index.html` in a browser.
